# 武器枪口接入

`1.6/Patches/WeaponMuzzles.xml` 配置全部 23 件手持枪械与喷火武器，覆盖原有装备及二期武器。坐标按实际 512×512 原贴图的枪管出口选取，以完整贴图左上角为原点，保留透明边缘。投掷手雷、近战军刀和建筑炮塔不使用手持枪口定位。

普通弹丸、霰弹多弹丸、激光弹丸、切换弹种及必中特殊射击均经过原版 `Projectile.Launch`，由随包的枪口库统一校正。命中、伤害、射程、弹匣与射速由原有动词继续负责。

HK416 的榴弹和霰弹下挂使用 `UnderbarrelMuzzleExtension.offset`，表示相对主枪口的归一化贴图偏移。`Patch_UnderbarrelMuzzle` 根据武器实例当前选择的动词调整坐标，再由库统一处理旋转、镜像、后坐力和墙体限制。主枪口编辑器的校准量同时平移下挂枪口；下挂相对位置维护在 XML 中。

`Patch_IncineratorMuzzle` 接管现有燃料喷火器的火流入队位置和飞行时长，保留 `Verb_ArcSprayIncinerator` 及燃料补丁。`IncineratorMuzzleUtility` 为火流和叠加火焰锥提供同一套持枪姿态、枪口与墙体截断终点；截断终点退到枪口后方时不绘制反向火流。伤害与目标范围预览仍使用原版光束逻辑。

`Patch_IncineratorMoteMotion` 将火焰粒子的初始两端放在实际枪口，并把出生帧贴片收为零。原版 `Mote_IncineratorBurst` 使用10格基础图形，且不会按连接端点自动缩放，因此每次更新同时修正尾巴端点和 `linearScale`：贴片纵向长度只覆盖已经飞过的距离，最长两格，宽度逐渐展开；尺寸换算消除 `graphicData.drawSize` 的再次放大。只标记本模组接管的粒子，标记使用弱引用随粒子释放；其它喷火器保持原版行为。

模组设置提供“打开枪口可视化编辑器”按钮，也可以从开发者菜单打开。保存的本地枪口覆盖优先于 XML，查看包内默认值时使用“恢复 XML 默认”。选中下挂时地图枪口标记包含下挂偏移，面板中的贴图坐标仍编辑主枪口基准。

构建通过项目引用生成并携带 `WeaponMuzzleFramework.dll`，部署前检查其存在；分发时保留库的原始程序集名称。只进行编译验收，不启动游戏；初始坐标和喷火视觉未标记为游戏内实测。
