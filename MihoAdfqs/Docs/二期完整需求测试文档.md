3. 数值测试优先使用标准品质和需求指定的基准材料，移除无关基因、服装、伤病、天气与地形干扰。
4. 每项填写通过、失败、未完成或未测；失败记录用例编号、复现步骤、实际数值、日志和模组列表。

## 边界与原文歧义

- 三期内容只验证二期保留的提示：特殊对话相貌和奇怪话题入口；专属机械体、大型防御建筑、米莉拉后续服装、升变与原力扩展不要求二期实现。
- 原文“全局学习速度100%”按种族基础值验收，佩尔克体等明确加成另行叠加。
- Q11 给出了中心／边缘伤害但未指定范围；辐射尘埃未给出持续时间或伤害速率；队长翻滚未给出距离。这些数值需在最终实现说明中明确，不能作为原文已指定值。
- 当前实现取值：Q11 采用3×3、中心一格140伤害、外圈40伤害；辐射尘埃沾染30秒，每秒增加1%毒性积累。两项均需在人工体验后评价效果。
- 用户已确认：“命运”完成后保留4名亲卫，只取消队长召唤；空降盔甲按全身外层护甲实现，并可与同系列头盔同时穿戴。这两项确认优先于原文笔误。
- 回收任务当前物资为聚乙烯400、工业级钢板200、医药40，交回各自的一半；救援队当前4人，其中3人受伤倒地；前卫进攻部队为20—50名智人种和米莉拉混合队伍。原文未规定这些数量。
- 轨道轰炸当前选择目标后延迟5秒；普通支援停留48小时。只有成功提交或任务完成才发放点数。
- 赫尔默实现取值：翻滚最多6格、持续0.5秒、冷却20秒；自爆半径3.9格、100爆炸伤害、150%穿透，死亡结算后下一游戏刻恢复。距离、持续时间、自爆数值和恢复延迟并非原文指定。
- 血液风暴以基础武器射程的40%进入近攻、65%退出，形成不同进出阈值；射击时间按瞄准和连发间隔乘算150%／75%。自动战斗默认开启，手动移动指令优先。
- 队长按原文同时拥有4号和45号基因：仅计算这两项时，远射承伤为15%×75%=11.25%，近攻为15%×50%=7.5%；佩尔克体、品质、装备与伤害类型另行结算。部位生命值也叠乘种族基础与专属基因倍率。
- 背景实现取值：魅力采用PawnBeauty加值；射击速度按连发间隔和轮次冷却耗时解释，多个指挥官不重复叠加；死宅以连续离开任意室内房间超过10小时判定，回到室内重置。老枪伤严重度3，烹饪教师心脏病采用20%冠状动脉阻塞。
- 医疗实现取值：摘除佩尔克体要求医疗8、4份工业医药、2400工作量，恢复后按有效基因从15%成长；同化保留原人物对象、性别、年龄、技能、背景、关系和记忆，重建身体及基因，不适穿衣物转入人物库存。兴奋剂基础成瘾概率2.6%，受原版人物药物系数影响；紧急剂饥饿速度为基础的5倍。不同来源的射击耗时倍率相乘，同名药效不重复叠乘。
- 堡垒实现取值：建造后须装入钢铁，切换费用从其500容量库存扣除100；每发再消耗1钢铁，弹仓计数不额外预扣库存。空仓装填5秒，断电暂停；88毫米可攻击原版飞行人物。泛光灯无遮挡范围为13×13、100%光照，墙体遮挡；培养机照亮自身4×8占地。
- 材料换算：标准品质、指定基准材料时按原文护甲和耐久验收，换材后按相对材料系数计算。工业钢板对衣物／武器耐久×4、建筑×4.3；聚乙烯分别×2.5／×2，建筑显示灰色、装备显示黑色。金属基准采用钢铁，布料基准采用布。
- 配方解释：国防军军帽兼容布料与金属、以布为基准；狐面按原文40木材采用木质材料。亲卫特殊护具占头部层，与队长制服共穿。原文陶瓷、异域物质与秘灵花分别引用美狐的Miho_Ceramics、Miho_ExoticMatter与RawPosFlower。
- 纪念面包使用500小麦、1秘灵花、1工业级钢板。已声明依赖中没有找到小麦，当前提供本模组可种植小麦，使用原版作物图；这是实现选择，尚无用户确认。
- 射击模式解释：多模式武器点射为3发，半自动为1发，全自动持续至弹匣用尽；只有点射选项的武器每轮1发。原文未指定点射发数。非整数射击间隔以余数累计，原版执行下限仍为每刻1发；精确命中距离按原文节点插值，并继续结算人物、品质、天气和掩体。
- 前卫的帝国守军在该任务地图内与玩家合作，即使地图外双方敌对；不改变全局外交。接取时无殖民地、未清理据点被移除、救援队全灭或奖励人物交付前死亡会失败。回收地点完成访问后可以撤回并提交物资。
- [专项边界测试](二期测试用例/13-专项边界测试.md) 补充特殊人物、外观、医疗、建筑、材料、射击与任务异常分支的具体复现步骤。
