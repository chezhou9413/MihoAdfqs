# 功能介绍图

这套图面向玩家，选取派系、人物、军械、支援、建筑和护盾六个模块。每项用一两句话说明用途，不在宣传图中放实现说明、操作入口清单和参数表。

采用暗血红基底、浅灰米色文字、铁十字徽记和项目现有贴图。攻击战备使用红色图标，援军与补给使用蓝色图标。全部通过代码排版绘制，没有使用生图服务。

参考[星环公司的工坊介绍图](https://steamcommunity.com/sharedfiles/filedetails/?id=3534748687)的实物贴图、功能标注与独立章节结构；不复用参考页面的插图或文案。

## 成品

默认输出到 `E:\ModdevMics\Outputs\MihoAdfqs\PlayerIntroduction`，压缩包为上级目录中的 `MihoAdfqs_玩家介绍图.zip`。图片是项目宣传输出，不加入游戏自动加载目录。

| 文件 | 内容 |
|---|---|
| 01_美狐第三帝国 | 派系内容与帝国联络 |
| 02_帝国人物 | 秋霜、赫尔默与提亚娜的身份和主要能力 |
| 03_帝国军械 | 制式武器、下挂、电磁激光与超新星重炮 |
| 04_轨道支援 | 六种攻击战备、五种援军与补给的用途 |
| 05_帝国建筑 | 堡垒、医疗舱、培养机与工业设备 |
| 06_个人护盾 | 两件护盾装备与受击、破碎、充能效果 |

六张原尺寸PNG宽1200像素；同名SVG保留文字和矢量图形并嵌入实际贴图。`Workshop640`提供640像素宽的版本，另有总览拼图、完整工坊长图和本地HTML预览。人物、护盾与舱内内容为介绍示意。

## 重新生成

在项目目录使用已有Pillow环境运行：

```powershell
& 'C:\Users\30978\.cache\codex-runtimes\codex-primary-runtime\dependencies\python\python.exe' 'Tools\Promotion\build_feature_guide.py'
```

可以传入 `--output` 指定其他输出目录。使用系统黑体、等线及Bahnschrift字体，不需要联网，不启动游戏。提亚娜的身体、空白脸型与翅膀从当前已安装的米莉拉前置读取，路径位于 `sprites.py`；服装、头发、光环及特殊表情使用本项目资源。修改安装位置后需调整该路径。

人物合成时，脸、五官、头发、耳朵和帽子一起缩放，并与衣领对齐。美狐头部参考种族定义的0.75比例，提亚娜使用米莉拉身体和空白脸型后覆盖自己的五官。

攻击战备与补给文案保存在 `Assets/Promotion/support.json`，其他模块文案在 `feature_panels.py` 中。

PNG会实际测量中文宽度并换行；SVG使用系统字体，跨机器编辑时需安装对应字体，发布直接使用PNG。
