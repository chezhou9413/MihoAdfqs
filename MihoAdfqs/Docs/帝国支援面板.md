# 帝国支援面板

入口：轨道通讯器 → 联络第三帝国 → 帝国支援·作战面板。首次联络对话完成后显示此入口。

目录包含六项原有支援与五项轨道打击，共十一项。所有图标均手工绘制SVG，导出512×512透明PNG；六项轨道打击以低饱和红色为主，共用上方炮弹入射、下方椭圆打击区的构图，细节区分单发、火力网、汽油、毒气与EMP。士兵、药物、蓝图、亲卫及动员以低饱和蓝色为主，用灰米色点缀识别细节。支援、总部联络、确认窗口、状态条及装弹面板统一使用暗血红主底（约#420E11）、稍浅的血红卡片（约#4F1316）、深红横带与柔和红色边线，文字为灰米色，保留帝国标志。面板图标压低亮度，不做亮度呼吸；悬停只做小幅提亮，接通指示灯保留缓慢轻微的呼吸效果。

单发轰炸绘制一枚炮弹；火力网绘制多枚炮弹与散布环，120mm与380mm有口径标识，汽油弹配火焰，毒气使用防毒面具，EMP使用脉冲闪电。地图使用无底板的透明图标，加浅色细轮廓且不再压暗乘色；图标实际显示68×68像素，下方是暗血红圆角计时条，直接显示一位小数的剩余秒数，并使用红色或蓝色圆环区分打击与支援。圆环采用96段抗锯齿圆弧、连续末段角度及圆形端帽，按原版刻间余量插值，暂停时保持画面。同一落点的多个图标按图标、计时条及当前字体实际高度排列，避免计时条重叠。名称、投送阶段和友伤提示放在悬停说明中；持续火力网到达后，计时条显示20秒炮击阶段的剩余时间。HD2Original与HD2图标映射.csv只保留此前参考素材的溯源记录，当前导出工具不再读取这些资源。

支援中心从下达指令起显示红色定位光柱，持续到该项交付或火力网结束。光柱沿屏幕上方投影18格，复用现有战斗光束Shader，带红色光晕、明亮细芯、1.25秒周期的柔和脉冲和地面扩散光环。脉冲跟随游戏刻间插值，暂停时停止；同一格的多项支援共用一根光柱，不创建临时GameObject或额外计时队列。

点数支援先选择地图落点，确认有效落点后扣点；取消选点不扣费。亲卫入口复用元首技能的可用性、范围、施法任务、队长确认与冷却。永久动员须确认后开启，保留元首心情−10的代价。

执行队列显示剩余时间、投送阶段、落点与进度。倒计时以游戏刻为准，暂停时停止，加速时随游戏速度推进。空投最终落点按附近地形调整：蓝色大圈为预定区域，小圈标出实际空投舱位置。

120mm、凝固汽油弹和380mm火力网均7秒到达；单发精准打击、毒气与EMP均3秒到达，包含最后0.5秒的炮弹入射。所有范围按直径计算，伤害不随距离衰减：

火力网圆圈表示炮弹中心的散布区，边缘爆炸可能波及圈外；每发炮弹均有实体弹道及半透明拖尾。首次弹着在7秒，后续按间隔发射；队列及地图图标保留至20秒持续阶段结束。暂停和保存后继续按原游戏刻推进。

燃烧弹在可通行且不灭火的格子铺设原版燃油，解决裸土或石地缺少燃料导致点火失败的问题；对范围内可点燃的目标逐个尝试点燃，初始及已有火势至少1.5。水面、灭火泡沫与完全不可燃单位仍遵循原版规则。

毒气使用Biotech的原版ToxGas；未加载Biotech时入口明确禁用。可中毒的肉身单位接触帝国毒气区后进入原版恐慌逃跑，单次最多10秒，离开毒气区后解除。同一次暴露不反复发送恐慌事件；机械族、完全毒素免疫或完全毒环境免疫单位不受恐慌影响。此效果也可能作用于友军。

购买轨道轰炸为3秒弹着、6×6范围、5000爆炸伤害；最后0.5秒由可保存的实体Skyfaller炮弹飞行并在落地时结算伤害。永久动员仍每30秒安排舰炮，使用3秒弹着时间，包含最后0.5秒的入射阶段。所有轰炸都会伤及范围内友军。

轨道炮弹飞行速度参数为1.6，在保留30刻入射时间的同时，将原版加速轨迹的初始视觉距离提高至原先约2.13倍，本体绘制尺寸为1.1×3.2格；使用已有战斗Shader绘制36格长、1.6格宽的半透明拖尾，叠加0.55格宽、88%基础透明度的白色内芯，沿尾部逐渐收细和淡出；毒气外尾为绿，EMP为蓝，其余为橙白。精准打击、高爆火力网和燃烧弹落地时额外产生14～24团向外喷射的灰尘，以及7～12块沿抛物线飞起、落地滑行的碎石；使用原版Fleck系统，不生成临时GameObject。入射、120mm/380mm爆炸、汽油、毒气、EMP以及放置成功后的战备呼叫声均来自本机HD2音库。120mm使用炮兵爆炸音色并提高音调，380mm使用更低沉音调；原有精准打击保留已导入的MihoCombat_OrbitalBlast。来源、媒体ID与SHA256见Sounds/Combat/HD2/Support/HD2支援音频来源.csv，入射与爆炸用途由CLAP候选匹配确定。

支援放置成功后播放战备球落地展开的公共启动层，替换此前的界面提示音。通过HD2战备球组件参数中的红色启动事件747886、蓝色启动事件1032351623，在本机foley_player Bank核对各自的播放动作1003338319、226268198，两者均指向公共层706071705。合成该层三个随机组的固定变体465632577、612965449、497066532，保留相对增益与展开顺序；不包含红蓝专属持续提示层及Wwise插件合成声。取消选点和无效请求不播放。单独导入工具为Tools/Combat/ImportStratagemBallAudio.py，事件证据及原始Bank、WEM哈希见同目录StratagemBallEvent.json；未启动游戏试听验收。

空投用固定120刻的原版空投舱，保留落地后的110刻开舱延迟。地图倒计时表示舱体落地时间，开舱后物品与士兵才可用。执行队列和飞行物引用参与保存。
