# 弹药界面配置

弹匣动词 `MihoAdfqs.Combat.Weapons.VerbProperties_Magazine` 支持在 XML 中设置 `weaponType`。类型只控制图示、余量消耗动效和装填文案，不改变射弹、伤害、容量或装填耗时。

```xml
<verbs>
  <li Class="MihoAdfqs.Combat.Weapons.VerbProperties_Magazine">
    <verbClass>MihoAdfqs.Combat.Weapons.Verb_Magazine</verbClass>
    <defaultProjectile>MihoPhase2_Projectile_SupernovaLaser</defaultProjectile>
    <weaponType>Laser</weaponType>
    <magazineSize>300</magazineSize>
    <reloadSeconds>3</reloadSeconds>
    <!-- 其余射击参数继续按武器定义填写 -->
  </li>
</verbs>
```

| weaponType | 界面图示 | 消耗和补充表现 |
| --- | --- | --- |
| Bullet | 细长子弹 | 扣弹飞出、装弹；未填写时默认使用 |
| Shell | 粗大的炮弹 | 扣弹飞出、装弹 |
| Rocket | 带尾翼的火箭 | 扣弹飞出、装弹 |
| Grenade | 榴弹／手雷 | 扣弹飞出、装弹 |
| Shotgun | 平头霰弹壳 | 扣弹飞出、装弹 |
| Laser | 带闪电符号的能量格 | 原位消耗脉冲、充能 |

主枪和下挂的每个 `verbs/li` 可以单独填写。枚举名称按表中大小写使用。普通 `VerbProperties` 没有此字段，只有弹匣动词支持该界面；配置 `weaponType` 不会把普通武器转换成弹匣武器。

现有超新星重炮发射器和 Q11 使用 Shell，激光步枪使用 Laser，HK416 下挂榴弹和聚变手雷使用 Grenade，AA12 和 HK416 下挂霰弹使用 Shotgun。电磁步枪仍然发射实体子弹，因此保留 Bullet。

界面自动保持单排排列。大容量弹匣／能量储备用一个图标表示多次射击，部分填充显示该组实际余量，悬停可查看每个图标对应数量。激光的头顶装填进度同步显示“充能”。

SVG 源文件位于 `Assets/UI/Weapons`，`Tools/Combat/RenderMagazineIcons.cjs` 导出透明 PNG 到游戏纹理目录。

爆炸武器的命中效果继续由弹丸 `CombatVisuals` 和现有命中入口控制，与弹药界面类型独立。铁拳火箭、Q11、HK416 下挂榴弹、重炮高爆／纳米／辐射弹、88 毫米高爆炮和聚变手雷的爆炸效果包括冲击环、烟雾以及向外飞散的尘土和火花；霰弹命中不产生爆炸闪光。
