# 建筑操作面板

只有医疗舱保留“医疗舱管理”窗口，用于原版冷冻舱没有覆盖的患者、药物搬运与手术。窗口采用现有暗血红配色，内容可以滚动；游戏继续运行，进度与暂停原因随设备状态更新。

- 医疗舱：选择操作者，安排药物搬运、倒地患者或尸体入舱，也可以让操作者本人入舱。草药、医药、闪耀医药每份分别提供1、2、8点，实际搬运数量不超过剩余容量。患者入舱后可查看治疗说明、选择缺失部件重建、复活或确认种族转换。手术费用在开始时支付；断电暂停，弹出会取消手术且不退费。
- 打印机、聚合器、酒桶、药物制造台：在原版账单页添加配方和设置次数、暂停、人员及材料范围；自动加工设备的进度和暂停原因显示在选中信息中。
- 堡垒：原版库存条显示钢铁，选中信息显示弹仓与装填倒计时。补给使用原版搬运工作和右键指令；换炮使用现有切换Gizmo，强制攻击使用原版攻击按钮。通电、装填完成且未开启停火时自动索敌，沿用原版敌我判定和目标评分；视线忽略自身4×4底座，外部墙体及致盲烟雾仍遮挡目标。炮管瞄准、射弹起点和枪口火光共用偏移后的炮轴，30毫米与88毫米分别按贴图尖端定位，换炮后立即使用对应位置。
- 培养机：使用原版选择作物Gizmo；种植人员可进入4×8培养区，全部32格均可播种，通电时自动收获。收获物放在培养区外，避免挡住重新播种的位置。植物的显示网格集中在中央玻璃窗口，内衬在下、植物居中、半透明顶盖在上，继续使用原版成长、分丛和风摆。
- 农业泛光灯：选中时显示13×13覆盖和供电状态。

医疗舱先在管理面板中安排装填药物。选中能行动的殖民者，右键医疗舱选择“入舱治疗”，即可让本人进入。右键“管理医疗舱”会把选中的人物带入面板作为操作者；倒地患者与尸体由面板安排搬运。舱内有人、药物不足或无法到达时，菜单显示具体原因；候选药物明确标出本次搬运份数和堆栈位置。

医疗舱内的患者面朝上躺在中央可见区域，使用本人的种族、服装与表情图层；尸体也按本人外观显示。内衬保留静态网格缓存，人物和上方顶盖按原版动态绘制阶段更新，弹出后不再显示患者。

建造按钮使用完整外观，堡垒图包含底座与炮管。蓝图保留原版蓝图染色，以半透明完整贴图显示；悬停预览沿用原版可建造／不可建造提示色。堡垒素材由现有图层通过SVG组合，源文件保存在`Assets/UI/Buildings`，导出入口是`Tools/Phase2/RenderFortressArtwork.cjs`。
