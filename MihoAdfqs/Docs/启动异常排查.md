# 启动异常排查

2026-10-04 的 Player.log 显示，MihoAdfqsMain 在 Mod 构造阶段执行 Harmony.PatchAll，对 AlienRace.HarmonyPatches.BirthOutcomeHelper 安装补丁时触发 HAR 静态构造函数。此时 LoadedModManager.CreateModClasses 尚早于 XML 加载及 DefOf 绑定。

HAR 因而提前安装整组补丁，PawnApparelGenerator 的静态初始化读取未就绪的 StatDefOf.MarketValue，PregnancyUtility 的静态字典使用未就绪的 PawnRelationDefOf 键，分别产生空引用与空键异常。HAR 自身初始化最终失败，美狐 Mod 构造也失败。原版加载随后在 PawnApparelGenerator.Reset 处中断，留下 ThingDef.ResolveIcon、CharacterEditor 快捷键及 ScreenshotTaker 的连锁异常。

修改范围仅为 MihoAdfqsMain 的补丁注册时机：构造时安排 LongEventHandler.ExecuteWhenFinished，在加载结束后的主线程执行 PatchAll。现有补丁均针对运行中的游戏功能，不需要在 Def 解析前安装。没有修改 HAR、Harmony、存档或启用列表。

使用当前 Steam 游戏、HAR 与 ChezhouLib 引用进行 Release 编译成功；已替换 Steam Mods/MihoAdfqs 中的 MihoAdfqs.dll 和 PDB，并核对 SHA256。没有重新启动游戏进行运行时验证，需要用户重新启动后查看新的 Player.log。

原日志、源文件和部署前 DLL 备份：`E:\ModdevMics\Backups\MihoAdfqs\startup-fix-20261004-084329`。同时补齐 DPA AI 自身 About.xml 的 Harmony 工坊链接，消除它的依赖元数据警告；其他 Mod 的元数据提示未改动。
